# 🏛 Alpha Epsilon Pi Gamma Chi Chapter Website

## 📌 Project Overview
The **Alpha Epsilon Pi Gamma Chi Chapter Website** is a secure, all-in-one platform designed to streamline communication, event planning, and financial management for fraternity members. The website will serve both **active brothers** and **potential new members**, offering essential resources, announcements, and a secure login portal for members to manage fraternity-related activities.

## ✨ Features

### 🔹 Public Front Page
- Introduction to **Alpha Epsilon Pi Gamma Chi** (mission, history, and values).
- Showcase of recent **events and chapter highlights**.
- Contact information for **potential new members**.

### 🔹 Secure Member Login
- **Accounts created by the Executive Board** upon initiation.
- First-time users will **receive a temporary password** and set a new one.
- **All passwords are securely hashed** for protection.

### 🔹 Member Dashboard
- 📢 **Announcements Board** – View important fraternity updates.
- 📰 **Newsletters** – Stay informed with past and upcoming newsletters.
- 📅 **Event Information** – View and RSVP for upcoming fraternity events.
- 💰 **Finances & Dues Payments** – View outstanding dues and make payments directly.

### 🔹 Admin Features (For Executive Board Members)
- **User Management** – Manage accounts, roles, and permissions.
- **Event & Announcement Management** – Create and edit upcoming events and chapter-wide announcements.
- **Financial Management** – Track payments, send reminders, and generate financial reports.

## 🛠 Tech Stack
- **Frontend**: HTML, CSS, JavaScript (React.js or another framework)
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT & bcrypt for password hashing
- **Hosting**: TBD (AWS, Heroku, or Firebase)
- **Payment Processing**: Stripe or PayPal (for dues payments)

## 🔐 Security & Data Protection
- **User data stored in a secure MongoDB database**.
- **Passwords are hashed** using bcrypt to prevent unauthorized access.
- **Role-based access control** ensures only exec members can manage user permissions and financial records.
- **Secure transactions** for dues payments using an encrypted payment gateway.
